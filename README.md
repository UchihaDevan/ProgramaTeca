# ProgramaTeca

Bem-vindo ao repositório do **ProgramaTeca**, um sistema desenvolvido em Java para a gestão de livros e usuários de uma biblioteca virtual. Este projeto combina conceitos de programação orientada a objetos com práticas de gerenciamento de dados, sendo ideal para aprendizado e aplicação prática.

## Recursos do Projeto
- **Cadastro de Livros**: Adicione, atualize e liste informações sobre os livros da biblioteca.
- **Gestão de Usuários**: Permite cadastrar e gerenciar dados dos usuários.
- **Consulta e Relatórios**: Visualize listas organizadas de livros e usuários.
- **Interface Intuitiva**: Desenvolvida para facilitar a experiência do usuário.

## Tecnologias Utilizadas
- **Linguagem**: Java
- **Interface Gráfica**: Swing (ou modo console, dependendo da implementação final).
- **Controle de Versão**: Git e GitHub

## Como Executar
1. **Clone o Repositório**:
   ```bash
   git clone https://github.com/UchihaDevan/ProgramaTeca.git
   ```

2. **Abra o Projeto em uma IDE**:
   - Recomendação: IntelliJ IDEA, Eclipse ou NetBeans.

3. **Compile e Execute**:
   - Certifique-se de que o JDK esteja instalado (Java 8 ou superior).
   - Compile e execute o arquivo principal na pasta `src`.
